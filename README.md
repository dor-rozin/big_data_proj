**Big Data Course-**

This will be our project for big data course on BIU.

The project will contain the pipeline of-
1. Kafka - will get the unstructured data from REST API into kafka topics.
2. Spark - data extraction from Kafka, transformations and calculations. Using AI capabilities in between to get some findings.
3. Save all final data into ElasticSearch.
4. Pull al final data from ElasticSearch and create a dashboard showing findings by the AI and by our calculations.
